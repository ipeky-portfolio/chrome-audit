# Audit Scope (Chrome)

## In-Scope

- Google Chrome Browser auf Windows 10/11
- User-Profile
- Registry- und Policy-Einstellungen
- Erweiterungen/Add-ons

## Out-of-Scope

- Andere Browser
- Netzwerkgeräte / Firewall
- Cloud-Dienste

## Voraussetzungen

- Administratorrechte
- Zugriff auf User-Profile
