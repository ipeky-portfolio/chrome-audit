# Google Chrome Security Audit – CIS-ähnliche Benchmarks

## Übersicht

Dieses Projekt demonstriert ein Security-Audit für Google Chrome Browser.  
Die Bewertung basiert auf CIS-ähnlichen Best Practices für Browser-Härtung.

## Ziele

- Überprüfung sicherer Chrome-Konfigurationen
- Identifikation von Abweichungen
- Risikobasierte Bewertung
- Handlungsempfehlungen

## Scope

- Chrome Version ≥ Latest Stable / ESR
- Windows Clients 10/11
- User-Profiles
- Policies (Enterprise / MDM)

## Audit-Kategorien

- Safe Browsing / Phishing-Schutz
- HTTPS / SSL Enforcement
- Password & Autofill
- Extension Management
- Data Collection / Telemetry
- Pop-ups / Downloads / Plugins
- Proxy / Network Settings

## Bewertungskriterien

- Konform
- Nicht konform
- Nicht anwendbar
- Manuelle Prüfung erforderlich

## Zielgruppe

IT Security Teams, Auditoren, DevSecOps
